# Hotel Opulence Web Application

A modern hotel reservation web application built with [Next.js](https://nextjs.org).

## Requirements

- Node.js 18.17.0 or later
- PNPM 8.0.0 or later

## Getting Started

First, run the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to access the Hotel Opulence website.

## Current Features

- Modern and intuitive hotel room booking interface

## Upcoming Features

- Real-time availability checking
- Secure payment processing
- User account management
- Booking history and management
- Administrative dashboard

## Tech Stack

- Next.js 14 for the frontend framework
- Modern UI with responsive design using [Joy UI](https://mui.com/joy-ui/)
- [Material UI Icons](https://mui.com/material-ui/icons/) for consistent iconography
- [next/font](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) with Geist font
- Backend API integration
- [PNPM](https://pnpm.io/) for fast, disk space efficient package management

## Development

You can start editing the application by modifying files in the `app` directory. The application features hot-reload, so you'll see changes in real-time.

## Deployment

The application is configured for deployment on [Vercel](https://vercel.com). For deployment instructions, refer to the [Next.js deployment documentation](https://nextjs.org/docs/app/building-your-application/deploying).
